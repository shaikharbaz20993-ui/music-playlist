# 🎵 Music Playlist Project (C++)

## 📌 Description
This is a simple Music Playlist project built in C++.  
It uses a **doubly linked list** to manage songs in a playlist.  
You can add, delete, and navigate through songs like a real music player.

---

##  Features
- Add new songs to playlist
- Search a song
- Delete songs from playlist
- Move to next song
- Move to previous song
- Display current playlist
- Circular navigation of songs (if implemented)

---

##  Data Structure Used
- Doubly Linked List

Each song is stored as a node with:
- Song name
- Pointer to next song
- Pointer to previous song
